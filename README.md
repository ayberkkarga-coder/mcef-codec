# MCEF Codec

A Chromium browser for Minecraft **26.2**, with the H.264 and AAC codecs that ordinary Chromium builds leave out. It is a library: on its own it renders nothing and adds no items. [Doomscroll](https://modrinth.com/mod/doomscroll) is what uses it.

- Minecraft **26.2** · Fabric · Java 25 · the browser runs on the client only (the jar also loads on a server, where it does nothing)
- CEF 126, from the [CinemaMod](https://github.com/CinemaMod/mcef) java-cef build
- Off-screen rendering straight into a GPU texture, browser audio delivered as PCM for the game to place in the world

## Install
Drop the jar in `mods/` together with `fabric-api`. On first launch it downloads the Chromium binaries for your platform into `config/mcef-codec/`.

| | |
|---|---|
| Download size | ~136 MB |
| Verified with | SHA-256 |
| Source | the official CinemaMod mirror, `mcef-download.cinemamod.com` |

The binaries are **not** bundled in this jar. They stay on the player's machine and carry their own licences, including those of the codecs they contain.

## What it provides
- `CefService` — one initialisation future for the whole game, with a progress value while the binaries download.
- `CefBrowserView` — an off-screen browser: navigation, mouse and keyboard input, JavaScript execution, console messages, a paint callback that uploads only the changed regions, and an 8×5 average-colour map of the frame (what doomscroll's ambilight reads).
- `CefAudioDefaults` / `CefLaunchOptions` — sample rate, chunk size and target backlog for audio, frame rate, user agent, a local page provider (`doomscroll://` style custom schemes), and the ad-blocker switch.
- A request-level ad blocker: EasyList and AdGuard rule syntax plus a hosts list, cached under `config/mcef-codec/adblock/` and refreshed weekly.

## Why a separate mod
Chromium is large and slow to start. Keeping it in its own jar means it initialises once for every mod that wants a browser, and one download serves them all. Splitting it also keeps the licences clean: this library is LGPL-2.1 because it descends from MCEF, while a mod that only uses it is free to pick its own licence.

## Building
`JAVA_HOME` must be a Java 25 (the Minecraft launcher's own JDK works).

```
./gradlew build
```

The jar lands in `build/libs/`. The mod icon is generated by `tools/make_icon.py` (`pip install pillow`).
